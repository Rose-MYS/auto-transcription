# 扒谱测试曲集（v1，2026-11-20）

每个文件夹是一首测试曲：
- `audio.mp3`：给扒谱工具的输入
- `answer.mid`（L1/L2 还有 `answer.musicxml`）：标准答案，用来和工具输出对比打分

按难度分三级，先从 L1 做起。

## 说明
- **合成曲（L1、L2）**：由 music21 写谱，用 FluidSynth + FluidR3_GM 音色渲染成音频。答案和音频完全一致，适合检查流水线是否跑通、量化和出谱是否正确。曲目均为公有领域。
- **真实录音（L3）**：取自 Google Magenta 的 [MAESTRO v3.0.0](https://magenta.tensorflow.org/datasets/maestro) 数据集。国际钢琴比赛选手在雅马哈 Disklavier 上演奏，琴键动作被同步记录成 MIDI，所以 `answer.mid` 是逐音精确的答案（但没有小节线和拍号，只能对比音符，不能直接对比谱面）。许可证 CC BY-NC-SA 4.0，仅限非商用。
- MAESTRO 元数据把 BWV 846 标成了第二卷，实际是第一卷。
- 还缺：真人演奏的单旋律录音（人声、长笛等）。常用的数据集（URMP、MIR-ST500）托管在当前云端环境访问不了的网站上，需要的话可以从你的电脑上下载。
