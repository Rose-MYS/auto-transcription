## 说明

- **音频**：用 yt-dlp 从对应 B 站视频中提取音轨（原视频多为钢琴演奏录像），
  保留原始 AAC/m4a 编码，没有二次压缩。部分视频带 Hi-Res / 杜比音轨，码率较高。
- **乐谱**：取自 [琴谱123](https://www.qinpu123.com/) 公开的钢琴谱图片，
  按曲目逐页合成 PDF（A4）。标注「五线谱+简谱」的条目，PDF 内含两种记谱版本。
- **选曲标准**：流行歌曲或影视（含动画电影、日剧）配乐的钢琴翻弹，优先选择
  播放量高、音质/演奏完成度较好的版本；避开教学、扒谱、合成器（Synthesia）
  以及《原神》风物之诗琴（非钢琴）类谱面。

## 推荐练习顺序

1. **入门**：夜的钢琴曲五 → 天空之城 → 大鱼 → 孤勇者
2. **进阶**：Summer → 千与千寻 → 起风了 → River Flows in You → The Truth That You Leave
3. **挑战**：卡农 → 你的名字·Sparkle → 克罗地亚狂想曲 → Lemon → Flower Dance → Merry Christmas Mr. Lawrence
