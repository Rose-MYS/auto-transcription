## 结论

- **音频可用**：15 首都是完整的 AAC 立体声音轨，时长 2.3–6.6 分钟，和视频时长一致。
- **乐谱只能当参考，不能当标准答案**：谱子是琴谱123 上别人编配的版本，和 UP 主实际弹的不是同一份编配，音符层面对不上。下面 3 首连调都不一样，说明是不同的编配或移调。
- 整体适合做 TASK-005 的"C 类：流行/影视翻弹"测试，用来看谱面、听回放，加上大致的调号/拍号对照。

## 需要注意

1. **解码**：m4a（AAC）不能被 librosa/soundfile 直接读，机器上也没有 ffmpeg。我已在 venv 里装了 `av`（PyAV，自带解码器），流水线读 m4a 要用它，或者先转成 wav/flac。`setup_env.ps1` 需要加上 `pip install av`。
2. **版权**：音频和乐谱都有版权，只能个人学习用。**不要提交进 git**，已在 .gitignore 排除。
3. **时长**：每首截取 60–90 秒测试，机器跑全曲太慢。
4. **测试集缺口**：15 首全是流行/影视翻弹。TASK-005 的 A 类（带 MIDI 的录音，能算音符准确率）和 B 类（公版古典的普通录音）还要 agent 自己找。
