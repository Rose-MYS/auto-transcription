## 1. 问题根因与改动方案

### 1.1 严格拍号评测（`evaluate.py` / `run_all.py`）
- 在 `score_metrics`、`beat_metrics`、`meta_metrics` 中保留原有宽松 `meter_ok` / `ts_ok` 逻辑不变，新增 `meter_exact = (est_ts == ref_ts)`。
- `run_all.py` 报告表新增 `严格拍号` 列，与宽松 `拍号` 列并排展示。

### 1.2 复拍子识别去除固定 bpm 上限（`_detect_compound`）
- **问题**：原实现硬限制 `bpm < 120.0`，导致 `L5-C02 Sparkle`（附点四分拍 `bpm ≈ 125.0`）被误判为 `4/4` 并在拍内打出 `52.4%` 三连音；同时只看全局 `r6 < 0.62`，使 `L5-B03 舒曼梦幻曲`（`4/4`，`r3=2.65`）被误判为 `6/8`。
- **方案**：统计至少包含 2 个起音聚类的拍中，满足三等分槽位 `{0, 1, 2}` 且三等分残差 `ee3 < 0.55 * ee4` 的节拍占比 `tf`（triplet beat fraction），要求 `n_multi >= 4 and tf >= 0.20 and r3 < 1.0 and r6 < 0.60 and bpm < 160.0`。
- **效果**：`Sparkle`（`tf=0.71, r3=0.33, r6=0.31`）与 `MCML`（`tf=0.60, r3=0.67, r6=0.45`）均稳定判为复拍子，且连音占比从 `52.4%` 降至 `0.0%`；`舒曼梦幻曲`（`tf=0.00, r3=2.65`）不再误判 `6/8`。

### 1.3 `6/8` vs `12/8` 与 `2/4` vs `4/4` 联合打分消歧
- **问题**：`L5-C06 MCML`（`12/8`）中 `beat_this` 给出的强拍间隔为 2 个附点四分拍（半小节 `6/8`）；`L5-C05 克罗地亚狂想曲` 与 `L5-A04 勃拉姆斯 Op.10-2` 存在 `2/4` vs `4/4` 半小节折叠。
- **方案**：
  - 复拍子 `M == 2` 时，比较 4 拍周期内偶数强拍（`ph` 与 `(ph+2)%4`）在标准化和声变化+起音强度 `_z(harm) + _z(onset)` 上的均值差 `|m0 - m2| >= 0.45`，强弱交替显著时升格为 `M = 4`（`12/8`），并取更强相位。`MCML`（`1.384`）升格为 `12/8`，`L4-05 摇篮曲`（`0.118`）保持 `6/8`。
  - 单拍子 `M == 2` 且经小节细分（`subdivided_from_bar`）或强拍纯度 `< 0.85` 时，结合 `mscores` 升格为 `4/4`（`L5-A04`、`L5-C05`）；高纯度真 `2/4`（`L3-04`、`L4-02`、`L5-A02`，纯度 `>= 0.98`）保持不变。

### 1.4 强拍纯度校验（`refine_audio_beats`）与噪音老录音回退
- **问题**：78 转老录音 `L5-B04 肖邦圆舞曲 Op.64-2` 中 `beat_this` 强拍周期极其混乱（`purity = 0.225`），原 Step 3 无条件锁定强拍导致小节线全曲错位为 `2/4`；`L5-B03 舒曼` 同样纯度偏低（`0.45`）。
- **方案**：
  - Step 2 处理 `gap1_frac >= 0.40` 时，改用 `med_ibi < 1.5 and not raw_comp` 替代 `med_ibi < 1.05`，保留 `L3-05 12/8` 慢拍的同时修复 `L5-A04`（`med_ibi = 1.06s`）。
  - Step 3 仅在 `subdivided_from_bar or purity >= 0.55` 时锁定 `audio_downbeats`；纯度低于 `0.55` 时保留原始 `beat_this` 节拍序列，交由音符特征 `detect_meter` 联合 `dom_m` 打分选拍数与相位（修复 `L5-B04` 为 `3/4`、`L5-B03` 为 `4/4`）。
  - 若经 `gap==1` 细分为 3 拍且 `bpm >= 200.0`（一拍一小节的快三拍，如 `L5-A03 海顿` `253.5 BPM`），记为 `3/8`（`beat_ql = 1/2`）。

### 1.5 机械速度力度判别（`is_mechanical_tempo`）
- **问题**：`L5-B01 萨蒂 Gymnopédie 1` 速度平稳（`med_r = 0.0149`），仅靠起音残差被误判为机械合成曲而走 `notes`。
- **方案**：在多声部/规律分支加入力度离散度约束 `vel_std < 5.0 and vel_iqr <= 6.5`（所有 L1/L2 合成曲 `vel_std <= 3.8, vel_iqr <= 6.0`，而萨蒂 `vel_std = 6.1, vel_iqr = 8.0`）。
- **效果**：L1/L2 全部保持 `notes`，L3/L4/L5（含萨蒂）15/15 全部走 `beat_this`。
