## 阶段 2：实现 `--beats auto`、强拍锁定与复拍子

### 代码改动
- `工作文件\bapu\midi2score.py`：
  - 新增 `is_mechanical_tempo`：基于音符起音对全局直线节拍网格的拟合残差（`med_r`、`p75_r`）与分段相位漂移（`drift`）自动区分机械速度与真人演奏（16 首 × audio/oracle 共 32 组 100% 正确分离，无任何文件名/等级硬编码）。
  - 新增 `refine_audio_beats`、` _best_bar_subdivision`、`_detect_compound`：
    1. 过滤伪节拍峰（`< 0.35 * med_ibi`）；
    2. 处理 `gap == 1` 主导的“一拍一小节”（如 `L3-02` 格里格圆舞曲 `med_ibi < 1.05s` 时按起音命中率在 `k∈{2,3,4}` 中选出 `k=3` 细分并锁定强拍；`L3-05` 慢速 `med_ibi >= 1.05s` 则保留慢拍交由复拍子 + `detect_meter` 判为 `12/8`）；
    3. 清洗强拍（去伪强拍、补双倍空档）并逐小节锁定拍数，防止局部多拍/少拍引起全局小节线漂移（`L4-03` 小节线 F 从 `0.405` 升至 `0.987`）；
    4. 复拍子检测（`e6/e4 < 0.62` 且 `bpm < 120`）与不破坏强拍的半速/倍频修正（半速阈值经 `L4-02` oracle 验证微调为 `med_ioi_ratio < 0.22 and bpm < 80`）。
  - 扩展 `Analysis.time_sig`、`quantize_onsets(..., compound=...)`、`build_part(..., time_sig, beat_ql=...)`。
- `工作文件\bapu\run_all.py` & `工作文件\bapu\evaluate.py`：支持 `--beats auto` 并按 `ana.time_sig` 报告与测评拍号。
