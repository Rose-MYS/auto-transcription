## 4. 最主要的 5 类失败模式（按影响排序）

### 1. 较快复合拍子（`bpm ≥ 120`）被截断为 `4/4` 满屏三连音 / 或半小节 `6/8`（影响最大）
- **例子**：[L5-C02_sparkle-p1.png](L5-C02_sparkle-p1.png) 第 1–20 小节（`4/4`、`tuplet_ratio = 0.524`）；[L5-C06_mcml-p1.png](L5-C06_mcml-p1.png) 第 1–30 小节（`12/8` 判成 `6/8`）。
- **原因**：`_detect_compound` 硬性限制 `bpm < 120.0`，而 Sparkle 附点四分拍速达 `125 BPM`，导致未能识别 `12/8`，退回 `4/4` 后每拍强行输出三连音；`L5-C06` 则是 `beat_this` 每 2 个附点四分拍输出一次强拍，直接锁定为 `6/8`。
- **建议**：将复合拍子检测与拍内三连音占比联动（当连续多拍三等分胜出且呈 2/4 拍周期时，放宽 `bpm` 上限至 ~150）。

### 2. 历史底噪 / 重 rubato 下 `beat_this` 强拍周期错判（`3/4` 变 `2/4` 或 `4/4` 变 `3/4` / `6/8`）
- **例子**：[L5-B04_chopin_waltz_op64_2-p1.png](L5-B04_chopin_waltz_op64_2-p1.png) 第 1–48 小节（`3/4` 圆舞曲输出 `2/4`，小节线全曲错位）；[L5-A04_brahms_ballade_op10_2-p1.png](L5-A04_brahms_ballade_op10_2-p1.png)（`4/4` 输出 `3/4`）；[L5-B03_schumann_traumerei-p1.png](L5-B03_schumann_traumerei-p1.png)（1947 年 Schnabel 慢板 `4/4` 输出 `6/8`）。
- **原因**：`beat_this` 对 78rpm 底噪和极端 rubato 强拍置信度下降时，当前 `refine_audio_beats` 无条件信任 `audio_downbeats`（不与音符自身的 `detect_meter` 分数交叉校验）。
- **建议**：当 `beat_this` 强拍间隔不稳或与 `detect_meter` 冲突显著时，引入音符低音/和声重音联合打分，而非单一听从 `audio_downbeats`。

### 3. 极平稳真人慢板被误判为“机械速度”（`beat_source` 误走 `notes`）
- **例子**：[L5-B01_satie_gymnopedie_1-p1.png](L5-B01_satie_gymnopedie_1-p1.png)（`beat_source = notes`，`rests_per_bar = 1.64`）。
- **原因**：`is_mechanical_tempo` 以 `med_r < 0.032` 为判据，萨蒂前奏曲极其均匀的慢板四分音符刚好落入阈值内，导致未启用踏板延音与真人休止符简化路径。
- **建议**：`is_mechanical_tempo` 应结合全局节拍误差与 `beat_this` 自身置信度/一致性，避免极简平稳真人录音被误分流。

### 4. 片段转调导致的调号偏移（主调与属调/五度混淆）
- **例子**：[L5-A03_haydn_fantasia_Hob17_4-p1.png](L5-A03_haydn_fantasia_Hob17_4-p1.png)（C 大调片段判为 `G minor`）；[L5-C07_flower_dance-p1.png](L5-C07_flower_dance-p1.png)（C# 小调判为 `G# minor`）。
- **原因**：75 秒截取窗口内包含属方向展开或转调段落，`temperleykostkapayne` 全局统计受后半段影响。

### 5. 高音区织体左右手切分失衡与同手多声部截断
- **例子**：[L5-C06_mcml-p1.png](L5-C06_mcml-p1.png) 第 1–11 小节（右手包揽高音旋律与伴奏，左手全小节休止）；[L5-A01_brahms_ballade_op10_1-p1.png](L5-A01_brahms_ballade_op10_1-p1.png) 第 2 小节低音长音被截断。
- **原因**：`split_hands` 固定音区先验偏低（`rh_c=67, lh_c=48`），对高音区双手交叉/伴奏无力；`hand_to_events` 单声部假设仍会截断同手持续音。
