## v3 核心改动

1. **CC64 延音踏板时值恢复（`load_notes_with_pedal`）**：在真人演奏路径读取 MIDI CC64 延音踏板区间，将踩踏板期间释放的音符延长至踏板抬起或同音高下次起音前。
2. **速度自适应量化与严格连音抑制（`quantize_onsets` / `quantize_dur`）**：
   - 仅当一拍内存在 3 个独立起音簇且覆盖三连音全部 3 个槽位 `{0, 1, 2}`、并满足严格误差比（`e3 < 0.45 * e4` 且 `e3 < 0.055`）时才启用三连音，消除 rubato 假三连音与 6/12/24 连音。
   - 依据拍速（`bpm >= 180` / `>= 115` / `< 115`）与拍内起音簇密度自适应选择八分或十六分网格，避免快曲无意义的 16/32 分碎片。
3. **同手时值整理与碎休止消除（`hand_to_events`）**：吸收小于 1 拍的碎休止空隙；真正停顿处将音符结束点对齐至拍边界，消除“附点休止 + 16 分休止”组合。
4. **真弱起小节（`build_part`）**：当首音落在第 1 小节后半且缺拍 ≤ 3/4 小节时，构建 MusicXML `<measure implicit="yes" number="0">` 不完全小节（`L2-03`、`L3-03`、`L3-05`、`L4-03`）。
5. **斯卡拉蒂 `3/8` 识别（`_detect_compound`）**：针对快速一拍一小节的 `3/8` 律动（`115 <= bpm < 175` 且拍内三等分误差显著低于四等分），将 `M=2` 映射为每小节 1 附点四分拍的 `3/8`。
